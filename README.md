# 🏠 House Price Prediction Web App

A full-stack Machine Learning project that predicts house prices based on user inputs like size, bedrooms, location, and condition.

🚀 Live Demo: https://house-price-predictor-5vls.onrender.com

---

## 📌 Features

- 📊 Predict house price using trained ML model
- 🌐 Deployed on cloud (Render)
- 📱 Works on desktop and mobile
- 🎨 Clean and interactive UI
- ⚡ Real-time prediction using API

---

## ⚙️ How It Works

1. User enters house details in UI  
2. Frontend sends data to Flask API  
3. API processes input using ML pipeline  
4. Model predicts house price  
5. Result is returned and displayed  

---

## 📊 Input Features

- House Size (sqft)
- Number of Bedrooms
- Age of House
- Location (Urban / Suburban)
- House Type (Apartment / Villa / Bungalow)
- Condition (Good / Excellent / Poor)
- Furnishing (Furnished / Semi-Furnished / Unfurnished)
